二、问题点

1.使用nvm install指令安装后，一直无法use该版本，提示 “activation error: Version not installed. Run “nvm ls” to see available versions.”

咨询AI，一直说是cmd权限不足，但是切换power shell还是不行。

三、解决方法

重新下载一个版本，放到nvm的根目录下，然后运行nvm ls可以查看已安装的几个版本了。

安装多个node版本后，可以查看npm默认缓存位置是什么？防止安装到系统盘符，以下是对应指令。

VScode中如何使用终端和Git拉取

当打开vscode的终端一直提示 “ vscode打开终端提示终端进程启动失败 ”，并且Git拉取也一直没反应时，解决方法是重新设置cwd。

1.打开“文件” -> “首选项”->“设置”。

2.搜索 “ terminal.integrated.cwd ”。

3.将Integrated:Cwd的目录设置为在资源管理下找的到的目录。

4.保存后重新新建终端或重新拉取代码就可以了。
