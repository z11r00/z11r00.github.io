如何用Eclipse运行SpringBoot项目

发表于2026-03-30|更新于2026-03-30|其他编程
|浏览量:

Eclipse下载

  1. 官网：https://www.eclipse.org/

  2. 选择更多版本 “ Download Packages ”

  1. 选择Java EE类的 “Eclipse IDE for Enterprise Java and Web Developers”。

  1. 选择自己操作系统的版本，以我为例，点击Download Links下x86_64

  1. 切换镜像下载，点击 “Select Another Mirror”，可以找到Asia(亚洲)下的China，点击链接就可以快速下载到本地了。

Eclipse安装

  1. 下载完毕后解压，然后点击 “eclipse.exe”就可以打开

  2. 指定工作空间，选择电脑上的一个文件夹

STS插件 安装

  1. 点击 “help”->”Eclipse Marketplace”。
  2. 搜索 “Spring Tools”，后安装。

  1. 查看是否有spring模板

点击 “File”->“New”->”Project”->”Spring Tool”

修改Maven位置

Eclipse中，不设置自己的maven会默认将依赖放到系统盘中，所以需要手动指定一下。

  1. 修改maven位置

打开windows->Preferences->Maven->Installations，add添加自己下载在本地的maven根目录。

  1. 修改maven设置

还是在maven下，打开User Settins，分别修改User Settins、User Toolchains、Local Repository为自己maven目录下对应的settings.xml文件等。

导入SpringBoot项目

  1. 开始导入

点击File->Import->Maven->Maven->Existing Maven Projects

  1. 选择项目勾选pom

  1. 等待maven将依赖下载完毕

项目运行

  1. build配置

右键项目，选择build path->Configure Build Path，找到Libaries。

  1. Java编译设置

Java Build Path中System library选择Alternate JRE，选择自己项目需要的JDK，然后找到Java Compiler，compliance level下拉一个版本。

3.开始运行

打开项目的启动类，比如SchoolApplication.java，然后右键Run As，最后就可以看到启动成功了。
